# 無線版BOMの取りこぼし確認

2026-11-03。部品選定を一巡した時点の整理。[候補・根拠](wireless-bom-candidates.md)と既存の`pcb/jlcpcb/assembly/ts52k-bom.csv`、README、Raytac Version Kを照合した。

## 集計

[仮BOM CSV](wireless-bom-draft.csv)は**19品種・81点／基板**。Basicは12品種・72点、Extendedは7品種・9点。コンデンサ12個、抵抗6個、ダイオード53個、残り10個で合計81個。VDDの5個構成に加え、モジュールVBUS枝の2.2 Ωを1個追加した。

このCSVは用途別の選定表。[参照番号付きBOM](../pcb/schematic-review/bom.csv)を無線版回路図から別途生成し、型番・数量の一致を確認した。実装座標はまだなく、JLC発注用CSVではない。通常品MDBT50Q-1MV2の集計に、秋月品や水晶の補助候補を重複計上しない。分類は取得時の部品ページ確認記録で、発注時の見積とは区別する。

## 残す部品と削除する部品

既存製造BOMのうち、そのまま残すのはマトリクスダイオード53個、USB ESD3個、USB-C1個、CC抵抗2個、リセットスイッチ1個の計60個。残りは無線版の21個へ置き換える。

削除対象は、RP2040、QSPIフラッシュ、12 MHz発振器、外部3.3 V LDO、これらの電源容量・プルアップ抵抗、USB/QSPI直列22 Ω、BOOTSEL用1 kΩ、エンコーダA/Bの10 kΩと100 nF。現行の無線BOMへ誤って重複転記しない。

モジュール内蔵のアンテナ・32 MHz水晶・REG1用インダクタは追加部品に数えない。REG0用10 µHとLF水晶・負荷12 pF×2は外付けとして計上済み。SWDはランドのみで、実装部品数には含めない。

キースイッチ52個、エンコーダ本体、スタビライザーなどの既存手付け・機構部品はこのJLC実装表の外。エンコーダ本体は従来のEC11互換品を継承する方針だが、完全型番は元の設計から未記載のまま。電池とケースは今回の選定範囲外。

## 数量の根拠

- コンデンサ12個: 1 µF×2、4.7 µF×4、100 nF×3、10 µF×1、12 pF×2。
- 抵抗6個: CC用5.1 kΩ×2、ISET用8.2 kΩ×1、ILIM用1.5 kΩ×1、TS用10 kΩ×1、VBUS用2.2 Ω×1。
- ダイオード53個: キー52接点＋エンコーダ押し込み1接点。
- 上記以外10個: MCU、充電IC、REG0インダクタ、LF水晶、USB-C、リセット、電池コネクタが各1個、ESDが3個。

## USB端子番号の訂正

READMEにあった「D+ / D− をパッド34 / 35へ」という順序は逆。Raytac Version K p17の表で**34がD−、35がD+**を確認して訂正し、無線版回路図でも同じ接続をネットリストで確認した。

回路図用の主要端子は次のとおり。

| 接続先 | モジュール端子 |
| --- | --- |
| VDD、SWDのVTref | 28 |
| VDDH、BQ24072 OUT | 30 |
| DCCH、外付け10 µHの片端 | 31。もう片端はVDD |
| USB VBUS | 2.2 Ωを介して32。4.7 µFはモジュール側 |
| USB D− | 34 |
| USB D+ | 35 |
| LF XL1／P0.00 | 17 |
| LF XL2／P0.01 | 18 |
| nRESET／P0.18 | 40 |
| SWDIO | 51 |
| SWCLK | 53 |

根拠: [Raytac Version K](https://cdn.sparkfun.com/assets/4/7/4/3/8/_nRF52840__MDBT50Q-1MV2___MDBT50Q-P1MV2_Ver.K_spec.pdf) p17–18。

## 完了した照合と次工程への引継ぎ

部品・GPIO・ライブラリと無線版回路図の照合は完了。2026-11-10時点ではPCBにも西端移設後の割当てを反映済み。以下は実機確認まで完了したという意味ではなく、部品探索を繰り返す未決一覧にも戻さない。

1. **GPIO18本の割当て済み:** [接続表](wireless-pin-assignment.md)にマトリクス6列＋10行＋エンコーダA/Bを記載。2026-11-10の西端移設後は、LF用P0.00/01、リセットP0.18、SWD、nice_nanoブートローダーのP0.15を避け、列6本は制限なしGPIO、上段入力6本は低周波・標準駆動専用GPIOを使う。回路図・PCBへ反映済み。現在のUF2は旧1×1検証用のままで、全キー設定の同期は[チェックリスト](zmk-pin-sync-checklist.md)に従う。
2. **VDD外付け構成は決定済み:** nice!nano公開回路とNordicの例に合わせて、4.7 µF＋1 µF＋100 nF×3を初版へ採用。[選定記録](capacitor-selection.md)とBOMへ反映した。内部容量を含む実効特性は検証済みとはしないが、その未確認を理由に部品決定を保留し続けない。
3. **USB保護の部品決定済み:** Nordic推奨とRaytac Version L p42を根拠に、モジュールVBUS枝へ2.2 Ω / C22939を採用。既存H5VU10Uを3個継続する。結線と保護性能の未検証範囲は[電源・USB入力ノート](wireless-power-input.md)に記録。挿抜波形・ESD性能は実機試験対象。
4. **ランド・配置条件を整理済み:** [照合記録](wireless-layout-check.md)にメーカー推奨寸法・禁止領域・極性等を記載。ライブラリ登録と回路図へのランド割当て・端子照合は完了。基板への反映はこれから。

USB100固定充電、TS固定抵抗、外付けLF水晶、REG0/REG1 DC/DCの決定は維持。SWDランドは必須、機材とモジュール購入先の決定は後日。電池の具体的な製品を選ぶ作業やケース設計はここへ戻さない。

19品種・81点を回路図へ反映し、参照番号・ランド・数量とERCを照合済み。[検査結果](../pcb/schematic-review/validation.json)を参照。実機起動の実証と、PCB実装座標を含む製造用BOMの確定はこれから。
