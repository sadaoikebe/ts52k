## モジュールの裏面実装とアンテナ

[Raytac Version L](https://www.raytac.com/download/index.php?index_id=43) p7、9、11、13〜17を基準にする。

- 図の寸法・ピン表示はTop View。B.Cuへ置くときはKiCadの面反転を使い、ピン番号を手作業で鏡像に並べ直さない。本体は10.5×15.5 mm、高さ2.05 mm。
- GNDはパッド**1、2、15、33、55**の全てを接続する。モジュール内部やシールドへの接続を期待して基板側を省略しない。
- アンテナ側の長さ**3.8 mm**の領域は表裏を含む全銅箔層で抜き、横方向にも可能な範囲で広げる。メーカーは基板端への配置を推奨している。B.Cu実装だからF.Cuの銅箔を残せる、とはしない。
- アンテナ直下以外にも、p9に示された**1.6×1.2 mmの局所的な実装面銅箔禁止領域**がある。標準フットプリントにも対応する禁止領域があるので残す。
- 調査したKiCad標準の全層アンテナ禁止領域は幅12.4 mm・長さ3.75 mm。メーカー図の3.8 mmへ合わせ、基板側で横方向も拡張する。標準フットプリントを置くだけで配置レビュー完了とはしない。

真鍮プレート、電池、金属部品との実際の距離と通信性能は配置後・実機で確認する。今回、その理由でプレートやケースの設計変更は行わない。

## 電源・水晶の配置

[TI BQ2407x SLUS810N](https://www.ti.com/lit/ds/symlink/bq24072.pdf) §12、付属RGT0016C図に従い、BQ24072の中央露出パッドはGNDへはんだ付けする。VSS(8)もGNDへ接続する。中央パッドを未接続や単なる放熱用NCにしない。INの1 µF、OUTとBATの各4.7 µFをIC直近へ置き、戻りを短くする。電流経路とISET/ILIM/TS抵抗のGND接続を整理し、細い共通配線で充放電電流を流さない。

TI例の周辺ランドは0.6×0.24 mm、中心間の対向距離2.8 mm。KiCad標準は0.825×0.25 mm、対向距離2.925 mmで外側へ長い。中央パッドとピッチは対応しており、この標準を採用するが、メーカー図の完全な複製とは記載しない。中央ペーストは分割し、開放された貫通ビアでペーストを吸わせない。サーマルビアを設ける場合はTIの塞ぎ方の指示と製造条件に合わせる。

REG0の10 µHはDCCH(31)–VDD(28)間に置き、その配線とVDD容量の帰路を短くする。VDDH(30)の10 µF、VBUS(32)の4.7 µF、VDD(28)の5個はそれぞれ対象端子へ寄せる。VBUSの4.7 µFは2.2 Ωの後に置く。

[Epson FC-12M図](https://download.epsondevice.com/td/pdf/brief/FC-12M_en.pdf)の推奨ランドは上表の寸法。調査したKiCad汎用`Crystal_SMD_2012-2Pin_2.0x1.2mm`は各0.6×1.1 mm、中心間1.4 mmなので、そのまま同一とは扱わない。メーカー図どおりの専用ランドを作り、XL1(17)・XL2(18)と12 pF×2を近接配置する。REG0のスイッチング配線やUSBデータ線を水晶端子間へ通さない。水晶2端子に電源極性はない。

## コネクタとESDの端子・極性

[JST PH仕様書](https://www.jst-mfg.com/product/pdf/eng/ePH.pdf) p2のSide entry SMT図とp4のS2B-PH-SM4-TBを基準にする。標準ランドは電気端子1×3.5 mm・中心間2 mm、固定金具1.5×3.4 mm。図の実装面とピン1表示を合わせ、**1=BAT+、2=GND**と基板に表示する。固定金具MPは信号端子として数えず、電源を配線しない。ケーブルを挿抜できる空間を確保する。電池の製品選定やケース設計は今回行わない。

USB-Cは[HROのTYPE-C-31-M-12](https://www.krhro.com/Product-Details/726.html)を継続。既存PCB内のパッドを読み、以下のネットを確認した。メーカー推奨図と全寸法を再測定したという意味ではない。

| USB-Cパッド | 接続 |
| --- | --- |
| A6、B6 | D+ → モジュール35 |
| A7、B7 | D− → モジュール34 |
| A4、A9、B4、B9 | USB VBUS。BQ24072 INと2.2 Ωの手前 |
| A1、A12、B1、B12、SH | GND |
| A5、B5 | 各々独立した5.1 kΩからGND |
| A8、B8 | SBU、未接続 |

[H5VU10U Rev.2.0](https://datasheet.lcsc.com/lcsc/2504101957_hongjiacheng-H5VU10U_C22395519.pdf)の機能図と既存PCBを照合した。既存D89/D90/D91は**パッド1がD−/D+/VBUS、パッド2がGND**で、極性は一致する。既存ランドは各0.5×0.7 mm・中心間0.8 mm。メーカー推奨J=0.50〜0.60、K=0.25〜0.35、M=0.55〜0.65 mmに対し高さが大きいため、無線版では上表のメーカー推奨範囲へ合わせる。部品型番・個数は変えない。

## SWD接点と初回測定

[Tag-ConnectのNLランド図Rev.B](https://www.tag-connect.com/wp-content/uploads/bsk-pdf-manager/2019/12/TC2030-IDC-NL-Datasheet-Rev-B.pdf)と[CTX配線図](https://www.tag-connect.com/wp-content/uploads/bsk-pdf-manager/TC2030-CTX_1.pdf)に対応する。

- 接点径0.7874 mm、ピッチ1.27 mm。位置決め穴は非メッキ径0.9906 mmが3個。既存PCBのJ2もこの寸法。
- 接点は実装面のCu/Maskのみで、Pasteには開口しない。既存J2もB.Cu/B.Maskのみだった。
- メーカー指定の禁止領域に配線・ビアを置かず、他信号を接点の0.508 mm以内へ近づけない。接点自身へ接続する線と、他信号の通過を区別する。標準ランドに禁止領域がなければ基板側へ追加する。
- 既存J2の1番は旧+3V3なので、無線版では必ずモジュール**VDD(28)**へ付け替える。2=SWDIO(51)、3=nRESET(40)、4=SWCLK(53)、5=GND、6=NC。
- VTrefは基板電圧の参照で、書き込み器の給電出力ではない。1.8 Vの消去直後から3.3 Vへの初期化後まで測定できるようにする。クリップを使うなら反対面も接触・保持可能な位置へ置く。

### J2の現在位置（2026-11-13、下段へ再移設）

- **裏面 (19.05, 115.0)、+90°。** 最下段の1.25Uキー MX5（中心x=7.144）とMX9（x=30.956）の間。表面から見るとMX5とMX9のキーキャップの境目の下で、MX4（2.25U）の南。基板の下端（y=121.444）の手前。
- 接点：西の列が北から5（GND）・3（nRESET）・1（VTref=nRF_VDD）、東の列が6（NC）・4（SWCLK）・2（SWDIO）。位置決め穴は南に1個（19.05, 117.54）、北に2個（18.034／20.066, 112.46）。
- 判定：J2のコートヤード（4.09×7.09 mm。接点・穴3個・接点間の禁止領域を含む）が、表面側の全障害物から2 mm以上離れること。障害物は、全スイッチの15.6×15.6 mm正方形、全スタビライザー（MX4・MX65の2.25U、MX60の2.75U、MX23の3U、計8ユニット）の本体、スタビライザーのワイヤー、エンコーダSW2のコートヤード。表面に他の実装部品はない（SW1・J1を含め他は全て裏面）。
- スタビライザー本体の寸法根拠：CHERRY「Keymodule MX」カタログ63ページ（PDF題名 SnapSwitches_04.06.pdf、2006-12-07作成、RS Components配布 <https://docs.rs-online.com/19cd/0900766b813d1126.pdf>）。Drilling patternでØ3.05穴はモジュール中心から7 mm、Ø4穴はそこから15.24 mm、2穴の間隔「A」は1×2〜1×2.75で23.8 mm、1×3で38.1 mm。ハウジングが通るプレート穴（Cutout of frame）は幅6.65 (+0.1) mm、スタビライザー中心線から最大4.2 (+0.1) mm、長さ12.3 (±0.05)／13.5 (±0.15) mm。PCB面でのハウジング外形は寸法記入がないため、各ユニットを「x＝スタビライザー穴中心±4.2 mm、y＝Ø3.05穴の外縁からØ4穴の外縁まで」とし、さらに0.2 mm広げて扱った。同じページの側面図を縮尺で読むとハウジング幅は約7.0 mm、y方向は中心から−8.4／＋10.1 mmで、この範囲に収まる。ワイヤーは左右のハウジング間でØ4穴の列±2 mmとした。
- 実測（J2コートヤード端から障害物端まで）：スイッチ本体は**MX5・MX9とも2.061 mm**（最寄り）、MX4まで10.79 mm。スタビライザー本体はMX4東側まで8.70 mm、MX4西側まで11.30 mm。スタビライザーのワイヤー（MX4）まで8.33 mm。エンコーダSW2までは271 mm。裏面部品のコートヤードとは最寄りD9まで28.0 mm。
- 基板端までは、コートヤードから2.90 mm、穴の縁から3.41 mm。`ANT_EDGE`からは遠い（y>82の南側、x=17以東）。
- 前の位置 (−0.6, 86.5) は、上の寸法でみるとMX4西側スタビライザーの本体範囲（x≧0.36）にコートヤードが掛かり、南の穴の縁も範囲内に入っていた。
- 探索：基板全体で、yを0.1 mm刻み、向き0°／90°ごとに、2 mm条件を満たすJ2中心のx区間を厳密に求めた（`search_sites.py`）。裏面部品のコートヤードと重ならず、条件を満たすのは最下段のキー間（MX5–MX9、MX9–MX14、MX14–MX23西スタビライザー、MX60両脇、MX81両脇など）と東端（MX71・MX74・SW2の周辺）だけだった。モジュールから近いMX3とMX7の付近はJ3・Q1・C22などの裏面部品と重なる。SWD配線が最短になるMX5–MX9間を選んだ（モジュールのSWD端子から直線で約44 mm。次点のMX9–MX14間は約56 mm、余裕2.57 mmのMX14–MX23間は約76 mm）。
- TC2030-CLIPの外形寸法はメーカー資料（NLランド図Rev.B、製品ページ）に記載がない。左右のMX5・MX9本体との間は各2.06 mmで、クリップがこの幅に収まるかは実機で確かめる。プレート・ケースとの関係も今回の範囲外。
- 配線はすべてB.Cu。モジュールから基板西端沿いに、西からSWCLK・SWDIO・VTref・nRESETの順（x=−1.5／−1.0／−0.5／0.0）で南下し、MX5の中央穴の南（y=115.0〜118.9）を東へ進む。nRESET・VTrefは西の列の3・1番へ西側から入る。SWDIO・SWCLKは南の穴のさらに南を回って東の列の2・4番へ東側から入る。J2.5は既存のGNDビア（16.074, 111.681）へつなぐ。[記録](../pcb/placement-review/README.md)

追加の実装部品を増やさず、GND、USB入力、充電IC OUT/VDDH、VDD、抵抗後のモジュールVBUSへプローブを当てられる箇所を確保する。初回はUSB給電、各電圧測定、SWD接続、確認済みブートローダー書き込み、VDD/UICR読戻し、USB認識、最小ZMKの順で試す。

## PCBへの引き継ぎ

2026-11-10のU5西端移設でGPIO割当てを更新した。ダイオードの向きを維持し、上段バスの入力6本は北側パッド4・6・8・10・12・14、下段の行6本は南側パッド37・41・43・44・46・48へ接続する。列6本は制限なしのパッド16・20・22・24・26・49を使い、ZMKで高駆動を明示する。[現在の割当て](wireless-pin-assignment.md)は回路図・PCBへ反映済み。[移設後の配置・配線](../pcb/placement-review/README.md)と[ZMK同期チェックリスト](zmk-pin-sync-checklist.md)を参照。

部品・GPIO・初回SWD経路は回路図・PCBへ反映済み。基板上のアンテナ禁止領域は `ANT_EDGE` で拡張した。各時点のERC・主要ネット・BOM・ランド参照の検査はリンク先の記録を参照する。実機の起動、LF精度、USB挿抜波形、ESD、通信距離は試作後の確認であり、ビルドやERCで実証したとはしない。
