# TS52K — 無線版

親指シフト（NICOLA配列）を前提に設計した、52キーの自作キーボードです。このブランチは、MDBT50Q-1MV2 と ZMK で動かす無線版です。ケースとプレートは RP2040 版と共通です。

解説記事: [親指シフトキーボードを作った話](https://qiita.com/sadaoikebe/items/e3715383058286457a23)

## 特徴

- **親指シフト専用設計** — かな入力だけでなく、英数レイヤーも親指シフトで打てる配列
- **52キー + ロータリーエンコーダ** — 50%サイズに親指キーを確保したレイアウト
- **ZMK** — 有線のときは USB HID、ケーブルを抜くと BLE
- **MDBT50Q-1MV2** — Raytac の nRF52840 モジュール。チップアンテナ付き。技適あり
- **USB-C が一つ** — 有線キーボード、充電、あとからの UF2
- **保護付きの LiPo** — 過放電保護はセル側。基板側コネクタはJST PH横挿しSMT、電池製品は後で選ぶ
- **JLCPCB で発注できる基板** — モジュールは在庫 0 なので、事前発注してから PCBA
- **FDM 3Dプリンタで出力できるケース** — 特殊な設備なしで製作可能

## 回路の構成

```
USB-C (J1) ─┬─ VBUS ─┬─→ BQ24072 IN（1 µF）
            │        └─ 2.2 Ω ─→ モジュール VBUS（パッド 32、4.7 µF）
            └─ D−/D+ ──→ モジュール パッド 34 / 35
                         ESD は H5VU10U。データ線に直列抵抗は置かない

BQ24072 OUT（4.7 µF）──→ モジュール VDDH（パッド 30）
BQ24072 BAT（4.7 µF）──→ JST PH 2極（1=BAT+、2=GND）──→ 保護付きセル

モジュール VDD（パッド 28）──→ J2 の 1 番。電圧は REGOUT0 = 3.3 V
モジュール ── 16本 ──→ キーマトリクス（6列×10行）
          ── 2本   ──→ エンコーダの回転（A=P1.11、B=P1.13）
          ── SWD ──→ J2 の 2 番 SWDIO（パッド 51）、4 番 SWCLK（パッド 53）
SW1 ──→ P0.18（nRESET）を GND へ。電源を切らずに 500 ms 以内の 2 回押しで UF2
```

モジュールは MDBT50Q-1MV2 です。P1MV2 との差はアンテナだけで、技適は両方にあります。外形は 10.5 × 15.5 × 2.05 mm、供給は 1.7〜5.5 V です。アンテナは削ったり、足したりしません。32 MHz と無線側のインダクタはモジュールの中にあります。GPIO は 48 本が 61 パッドに出ています。

### USB

J1 は HRO TYPE-C-31-M-12 のままです。CC1 / CC2 は 5.1 kΩ で GND、シールドは GND、D− / D+ / VBUS の ESD は H5VU10U です。D+ / D− の直列抵抗は、nRF の USB PHY に入っているので置きません。

PC に挿すと、ZMK は既定で USB HID に出します。ケーブルを抜くと最後の BLE プロファイルに戻ります。切り替えは `&out` で、選択は残ります。充電器のように HID を受け取らない相手では `OUT_BLE` にします。キーマップだけの変更は ZMK Studio が USB でも BLE でもできます。

VBUS（パッド 32）は、モジュールの USB 用 3.3 V レギュレータへの 5 V 入力です。充電 IC の出力はここへ入れません。

モジュールVBUS枝には、Nordic推奨・Raytac参考回路の2.2 Ωを入れます。C22939（0603・Basic）を1個、4.7 µFは抵抗の後、VBUSのESDは手前です。BQ24072 INは抵抗の手前から分岐します。[選定根拠と接続](notes/wireless-power-input.md)を参照してください。

### 電源

セルの電圧を VDDH（パッド 30）へ入れ、モジュール内のレギュレータでコアを作ります。ZMK の nice!nano v2 は `zmk,battery-nrf-vddh` で、このピンを読みます。外の 3.3 V で VDD と VDDH を短絡する結線にはしません。この基板には灯が無く、他の基板へ 3.3 V を出すピンもありません。

GPIO の High は REGOUT0 です。nice!nano のブートローダに合わせて 3.3 V にします。UICR の生の数値は、ブートローダのソースからは写していません。未設定のままでは VDD が 1.8 V になります。

検証済みのZMK main最小構成に合わせ、REG0（高電圧側）・REG1（無線側）のDC/DCを両方オンにします。REG1のインダクタは内蔵、REG0用にはDCCH（31）–VDD（28）へ10 µHのLQM18DN100M70L / C713281を外付けします。P0.13のVCCスイッチは置かず、この端子はrow6に使います。VDDHに10 µF、VDDには4.7 µF＋1 µF＋100 nF×3を置きます。[現行BOMと根拠](notes/wireless-bom-candidates.md)を参照してください。

LFクロックは外付け32.768 kHz水晶、XTAL/50 ppm設定です。FC-12M / X1A0000610008（CL=9 pF）をXL1（17）–XL2（18）へ接続し、各端子からGNDへ12 pFを1個ずつ置きます。

### 充電

充電 IC は BQ24072 です。パッケージは VQFN-16（RGT、3.00 mm × 3.00 mm）、リール品の記号は BQ24072RGTR です。T 付きの BQ24072T は使いません。TS の見方が違い、10 kΩ 固定では充電しません。

nice!nano v2の公開回路図はBQ24075表記です。量産でBQ24072を使ったという発言は[調査記録](notes/wireless-bom-candidates.md)に出典と限界を残しています。今回の72の選定は、公開図と型番が同一という理由ではなく、VDDHへ供給するOUTの電圧条件に基づきます。SLUS810Nでは72のOUTはVBAT + 225 mV（VBATが3.2 V以上のとき+150 / +225 / +270 mV。3.2 V未満で入力があるときは3.3 / 3.4 / 3.5 V）です。4.2 Vのセルなら上側は約4.47 Vです。75のOUTは5.4 / 5.5 / 5.6 Vで、最大はモジュールの供給範囲1.7〜5.5 Vの上に出ます。

ピンは SLUS810N のピン図です。

| ピン | つなぎ |
| :--- | :--- |
| IN（13） | USB 5 V。1 µF。過電圧保護は typ 6.6 V（6.4〜6.8 V）。バイパスの範囲は 1〜10 µF |
| BAT（2、3） | 保護付きセルのプラス。充電電圧は 4.2 V。4.7 µF |
| OUT（10、11） | モジュール VDDH（パッド 30）。4.7 µF。範囲は 4.7〜47 µF。入力が無いときは BAT とつながる |
| EN1（6）、EN2（5） | 両方 GND。USB100 で入力上限は 100 mA（90 / 95 / 100 mA） |
| ISET（16） | 8.2 kΩ / C25981をGNDへ。Basic優先で選定。KISET = 890 AΩで約108.5 mAの設定だが、実際の充電電流はUSB100の入力制限とシステム負荷にも制限される |
| ILIM（12） | 1.5 kΩ を GND へ。データシートの試験条件。USB100 の電流を決めるのは EN の側。開放にはしない |
| TS（1） | 10 kΩ を GND へ。パックの NTC は引かない |
| TD（15） | GND。充電終止を有効にする。開放にはしない |
| CE（4） | GND。High で充電が止まり、OUT は生きたまま |
| TMR（14） | 開放。タイマは既定値 |
| CHG（9）、PGOOD（7） | 灯が無いので未接続 |
| VSS（8）とサーマルパッド | 両方 GND。パッドだけを GND にしない |

セルの容量はまだ決まっていないので、500 mA（EN1 = High、EN2 = Low）にはしません。nice!nano の公称も 100 mA です。BQ24072 に過放電保護は無く、短絡保護はあります。基板に保護 IC は足しません。セルを切り離す SYSOFF は 75 と 79 のピンで、72 にはありません。ロードスイッチは足しません。

コネクタはJST S2B-PH-SM4-TB(LF)(SN) / C295747で、基板側は1=BAT+、2=GNDに統一します。電池の容量・外形・製品は後で選び、ケーブルの実際の極性を基板に合わせます。PHシリーズ共通の極性規約を意味しません。

### キーの配線

52個のキーは、1個ずつマイコンのピンには繋ぎません。6列×10行のマトリクスです。列を1本ずつ順に駆動し、10本の行の電圧を見て、どのキーが押されているかを判断します。キーごとにダイオードが1本あり、向きはカソードが行側です。

エンコーダの押し込みスイッチも、このマトリクスの6列目に入っています。キー52と押し込み1つで、接点は53です。エンコーダの回転（A相とB相）はマトリクスの外で、専用のピンが2本です。

列と行でマイコンのピンは16本、回転と合わせて18本です。PCB仮配置で方針を見直し、行10本と回転2本の入力を南側パッド3〜14へ集め、列6本は制限なしGPIOで高駆動にする方針を採用しました。ダイオードは反転しません。[採用方針と現在実装中の旧GPIO表](notes/wireless-pin-assignment.md)を区別してください。入力先のネット変更と高駆動のファームウェア設定は未反映です。

### 書き込み

通常のRaytacモジュールはAdafruit UF2ブートローダーなしを想定し、初回はJ2のSWDから書き込みます。検証対象はAdafruit 0.11.0のnice_nano用SoftDevice結合HEXです。秋月の書き込み済みモジュールも調達対案ですが、搭載版と電源初期化条件の照合が必要です。SWDランドはどちらでも必須、機材と購入先の決定は後日とします。[調査記録](notes/swd-equipment.md)を参照してください。

J2 は Tag-Connect TC2030 のランドだけです。部品は実装しません。

| ピン | つなぎ |
| :--- | :--- |
| 1 | モジュール VDD（パッド 28） |
| 2 | SWDIO（パッド 51） |
| 3 | P0.18（nRESET）。SW1 と同じネット |
| 4 | SWCLK（パッド 53） |
| 5 | GND |
| 6 | SWO。未接続 |

SW1 は TS-1187A-B-A-B のまま、P0.18 を GND に落とすリセットにします。BOOTSEL 用の直列 1 kΩ は残しません。nRESET のプルアップは内蔵です。

## ロータリーエンコーダ

SW2 は型番未確定の EC11 互換です。押し込みは `col6` に入っています。A/B の 10 kΩ と 100 nF は外します。nRF52840 の内蔵プルアップは 11〜16 kΩ（別の回答は 13 kΩ）で、RP2040 の 50〜80 kΩ を前提にした回路は移しません。

## 配置と製造

モジュールは B.Cu、真鍮の定位板 t=1.5 mm は F 面、電波は樹脂の底板側へ抜けます。承認書 2.3 は、アンテナの位置を全層で GND 無し、できるだけ広く、端の方が中央より良い、と書いています。エンコーダの金属筐体はアンテナの近くに置きません。モジュールの高さは 2.05 mm です。

MDBT50Q-1MV2 の JLCPCB 部品番号は C5118826 です。2026-10-31 の表示は在庫 0、Standard Only、X-ray 必須でした。在庫が無くても Parts Manager で事前発注し、私有庫に入ってから PCBA に出します。生基板の最少は 5 枚です。Standard はエッジレールが要り、レール幅のヘルプは最小 5 mm です。レールは製品の外形に残しません。自宅リフローは、事前発注が通らないときの予備です。

Fanstel BC840 は使いません。同じ机の上でも、MDBT50Q より距離の余裕が小さく、縁ゼロのアンテナ条件は残ります。

## ファームウェア

無線版はZMKです。開発は別リポジトリ`C:\Users\marur\zmk-config`で行い、本リポジトリはハードウェアを扱います。ZMK main `4dd95d7840eb3d5a3f59bb29fbf1ab054715ef85` / Zephyr 4.1.0で、TS52Kの1×1最小定義をビルド済みです。VDDH給電、REG0/REG1 DC/DCともオン、外付けLF水晶XTAL/50 ppm、USB/BLE、P0.18リセット。P0.13の`EXT_POWER`は使いません。GPIO18本の全マトリクスと親指シフトの実装は今後のファームウェア開発で行います。

## 開発環境

- **KiCad 10.0** 以降

無線版回路図のERCはエラー0・警告0です。[検査スクリプト](pcb/check_schematic.py)で電源・信号・BOM・旧マトリクスとの一致を確認し、[結果](pcb/schematic-review/validation.json)を保存しました。ライブラリ検査は[別記録](pcb/LIBRARIES.md)です。PCBは旧版なので、無線版DRC・schematic parityの検査はこれからです。RP2040版の0件という過去結果を現在のPCB整合の結果として使いません。

**`Tools → Update PCB from Schematic` では `Link footprints using reference designators` をオフのままにしてください。** フットプリントは Unique ID で回路図と紐付いています。

基板を編集する場合は、[`pcb/PLACEMENT.md`](pcb/PLACEMENT.md) の「やってはいけないこと」を先に読んでください。`PLACEMENT.md` が説明しているのは RP2040 版の配置です。編集後はベタを再充填し、DRC と製造データを作り直します。

```sh
kicad-cli sch erc                                   -o erc.rpt ts52k.kicad_sch
kicad-cli pcb drc --schematic-parity --refill-zones -o drc.rpt ts52k.kicad_pcb
```
