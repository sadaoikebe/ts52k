# TS52K — Revision 0.2

親指シフト（NICOLA配列）を前提に設計した、52キーの自作キーボードです。ハードウェア（回路・基板・ケース）一式をオープンソースで公開しています。

解説記事: [親指シフトキーボードを作った話](https://qiita.com/sadaoikebe/items/e3715383058286457a23)

## 特徴

- **親指シフト専用設計** — かな入力だけでなく、英数レイヤーも親指シフトで打てる配列
- **52キー + ロータリーエンコーダ** — 50%サイズに親指キーを確保したレイアウト
- **QMKベース** — ファームウェアはQMKで構築
- **JLCPCBで発注できる基板** — PCBA（部品実装込み）を想定した設計
- **FDM 3Dプリンタで出力できるケース** — 特殊な設備なしで製作可能

---

## Revision 0.2

Revision 0.2 は RP2040 を搭載した現行版です。回路・基板の設計と配置・配線は完了しており、既存のケースとプレートを共通で使用します。

キーマトリクスは 6 列 × 10 行です。KiCad 10 の検査結果は、DRCエラー・未接続・回路図との不一致が0件、シルク関連の警告が25件、ERCエラー・警告が0件です。[JLCPCB 向けのガーバー・BOM・実装座標](pcb/jlcpcb/README.md)を同梱しています。基板や回路図を変更した場合は再生成してください。

[基板レイアウトと編集上の注意](pcb/PLACEMENT.md)も参照してください。

## 回路の構成

```
USB-C (J1) ─┬─ VBUS 5V ─┬─→ TPS7A2433 (U3) ─→ 3.3V ─┬─→ RP2040 IOVDD
            │           │                            ├─→ フラッシュ (U4)
            │           │                            └─→ 発振器 (X2)
            │           └─ D91 (H5VU10U) ─→ GND
            └─ D+/D− ───┬─→ 22Ω ──→ RP2040 USB
                        └─ D89/D90 (H5VU10U) ─→ GND

発振器 (X2) ── 12MHz ──→ RP2040 XIN ──→ 内蔵PLL ──→ 133MHz / 48MHz(USB)

RP2040 ─ QSPI (22Ω×5) ──→ W25Q128JVS (U4)   起動時にここからコードを読む
       │                    └─ CS ─ 10kΩ↑3V3、1kΩ ─ SW1 ─ GND（BOOTSEL）
       ─ GPIO ×16 ──────→ キーマトリクス（回路図）
       ─ GPIO ×2 ───────→ ロータリーエンコーダ A/B相
       ─ SWD ───────────→ Tag-Connect (J2)
```

Raspberry Pi Pico のリファレンス設計をおおむね踏襲しつつ、キーボード向けに変更を加えた構成です。

### J1 — USB-Cレセプタクル（HRO TYPE-C-31-M-12）

USB 2.0 専用の16ピン品です。フル24ピンのType-Cから USB 3.x 用の高速差動ペアを省いたもので、キーボードに 3.0 の帯域は不要なため、安価で実装しやすいこれを使っています。

Type-C は裏返して挿してもピン配置が上下反転するだけで使えます。これに対応するため、`D+` を A6/B6 の両方に、`D-` を A7/B7 の両方に接続しています。`VBUS` と `GND` も複数ピンを束ねて電流容量を確保しています。

`CC1`/`CC2` はそれぞれ **5.1kΩ で GND** に落としています。ホストはこの抵抗値を見て「相手はデバイス側」と判定し、VBUS に 5V を供給します。**この抵抗がないと電源が入りません。**

`SBU1`/`SBU2`（オーディオ・DisplayPort 用の予備線）は未接続です。

シールド（`SH`）は **GND に接続**しています。

USB D+/D− の直列抵抗 R7/R8 は、QSPI にも使う **22Ω・C25092** に共通化しています。JLCPCB の Basic 部品を使い、少量 PCBA で部品種と段取り費を増やさないための意図的な選択です。Raspberry Pi の RP2040 設計資料は 27Ω を指定しており、本基板の 22Ω はその値からの設計上の変更です。USB 信号品質と互換性の実測はまだ行っていません。

### D89・D90・D91 — USB ESD保護

U2を個別のESD保護素子3個へ置き換えています。D89・D90・D91はいずれも **H5VU10U / C22395519** で、それぞれD−・D+・VBUSを保護します。各素子の1番を信号またはVBUS、2番をGNDに接続します。[JLCPCB 部品情報](https://jlcpcb.com/partdetail/C22395519)

フットプリントはすべてKiCad標準の `Diode_SMD:D_SOD-882D` です。ESDとUSB信号品質は未測定です。[JLCPCB向け出力](pcb/jlcpcb/README.md)は現在の基板から生成しています。

### U3 — TPS7A2433DBVR（LDOレギュレータ）

USB の 5V を 3.3V に変換する 200mA・SOT-23-5 のLDOです。TI TPS7A2433DBVR / C2866134 を使用し、EN（3番）をINに接続してUSB給電時に有効にします。NCの4番は放熱のためGNDへ接続します。入力コンデンサC3は4.7µF・25Vの0603、C69335です。

### U5 — RP2040（MCU）

デュアルコア Arm Cortex-M0+、133MHz、QFN-56（7×7mm）。

U5の端子パッド幅は **0.20 mm**、中央GNDパッド内には **穴径0.30 mmのビア4個**があります。このパッドとビアは、JLCPCBの2層・1 ozで製造・実装できる設計と判断しています。同様の条件でJLCPCBに発注された基板の実例は、[パッド寸法・製造実例](pcb/jlcpcb/README.md#rp2040-のパッドと-jlcpcb-の製造実例)を参照してください。パッド幅や中央パッド内ビアを理由に、ガーバー出力を止める必要はありません。

**電源系統が特徴的です。** RP2040 は内部に 1.1V のLDOレギュレータを内蔵しており、`VREG_VIN`(44) に 3.3V を入れて `VREG_VOUT`(45) から出た 1.1V を、`DVDD`(23, 50) で自分に戻して入れるという構成をとります。基板側では 1V1 ネットにパスコンを置くだけです。[RP2040 ハードウェア設計資料](https://datasheets.raspberrypi.com/rp2040/hardware-design-with-rp2040.pdf)

```
+3V3 ──→ VREG_VIN (44) ──→ [内蔵1.1Vレギュレータ] ──→ VREG_VOUT (45)
                                                            │
                                                          1V1ネット
                                                            │
                                                      DVDD (23, 50)
```

| ピン | 接続 | 用途 |
| :--- | :--- | :--- |
| IOVDD ×6 | +3V3 | IOバッファ電源 |
| ADC_AVDD | +3V3 | ADCアナログ電源 |
| USB_VDD | +3V3 | USBトランシーバ電源 |
| **VREG_VIN** | **+3V3** | **内蔵レギュレータ入力** |
| VREG_VOUT | 1V1 | 内蔵レギュレータ出力 |
| DVDD ×2 | 1V1 | コア電源入力 |
| TESTEN | GND | 製造テスト用。データシート通り接地 |
| EPAD | GND | QFN裏面サーマルパッド |

`RUN`(26) は 10kΩ で 3.3V にプルアップし、コンデンサで電源投入時のリセット遅延を作っています。Tag-Connect の RESET から引き下げることもできます。

### X2 — OC2EL89CJO-113YLC-12M（12MHz 発振器モジュール）

RP2040 の標準構成は「水晶振動子 + 負荷容量2個」ですが、この基板は**発振回路を内蔵した完成品モジュール**を使っています。部品点数が減り、負荷容量の調整も不要になる代わりに、コストは水晶より高くなります。

`XOUT`(21) を未接続にしているのがこの構成の目印です。外部から完成したクロックを注入する場合、`XIN` だけを駆動し `XOUT` は開放にするのが正しい使い方です。

`EN` は 10kΩ で 3.3V にプルアップして常時イネーブルにしています。

12MHz は RP2040 の要求仕様で、内蔵PLLがここから 133MHz のシステムクロックと 48MHz の USB クロックを生成します。USB は周波数精度に厳しいため、ここは妥協できません。

### U4 — W25Q128JVS（QSPIフラッシュ）

128Mビット = **16MB** のシリアルフラッシュ。

**RP2040 にはプログラム用の内蔵フラッシュがありません。** 起動時にこのチップからコードを読み出して実行（XIP）するため、これが無いと何も動きません。

データ線4本を並列に使う Quad SPI で接続し、各線に 22Ω の直列抵抗を入れてリンギングと EMI を抑えています（Raspberry Pi Pico には無い追加です）。`/CS` は 10kΩ でプルアップし、電源投入直後にフラッシュが誤ってコマンドを受け取らないようにしています。

16MB は QMK には余裕のある容量です（Pico は 2MB）。現在の C97521 は JLCPCB Basic ですが、小容量品との価格差や PCBA の段取り費は注文時の見積もりで確認してください。

### J2 — Tag-Connect TC2030-IDC-NL（書き込み・デバッグ端子）

SWD 接続用のフットプリントです。**コネクタ部品は実装しません。** 基板上はランドと位置決め穴だけで、専用のポゴピンケーブルを押し当てて接続します。

ピン番号は TC2030-CTX（Cortex 用ケーブル）と同じです。1 が 3.3V、2 が SWDIO、3 が RESET、4 が SWCLK、5 が GND、6 は SWO で未接続です。

"NL" は **No Legs** の意味で、基板を貫通する固定爪用の穴が不要なタイプです。押さえている間だけ導通するので、書き込み時は手で保持するか治具を使います。

完成品にピンヘッダが飛び出さず、ケースに穴も不要なため、外観と厚みを損ないません。

### キーマトリクス

回路図では `col1`〜`col6` と `row1`〜`row10` の計 **16本の GPIO** で、52個のキースイッチとロータリーエンコーダの押し込みスイッチ、合計53接点を読み取ります。各ダイオードは同じ向きで、カソードが row 側です。

| ネット | GPIO |
| :--- | :--- |
| `col1` 〜 `col6` | 22, 12, 6, 13, 14, 15 |
| `row1` 〜 `row5` | 2, 4, 16, 18, 20 |
| `row6` 〜 `row10` | 3, 5, 17, 19, 21 |
| エンコーダ A相 / B相 | 0 / 1 |

GPIO7〜11 と GPIO23〜29 の計12本は未使用です。エンコーダの押し込みスイッチは `col6` のマトリクスに含まれます。ファームウェアも新しいマトリクスに合わせる必要があります。

### SW1 — BOOTSEL ボタン

RP2040 は起動時に `QSPI_SS` が Low だと USB マスストレージのブートローダに入り、UF2 ファイルをドラッグ&ドロップで書き込めるようになります。SW1 はそのためのボタンで、`QSPI_SS_N` を **1kΩ(R14) 経由で GND** に落とします。

SW1 は [XKB TS-1187A-B-A-B / C318884](https://jlcpcb.com/partdetail/C318884) の上押し式タクトスイッチです。基板の裏面に実装し、裏面側から基板に向かって押します。本体は 5.1 × 5.1 mm、高さは約 1.5 mm です。押しやすさとケース底板との隙間は実物で確認してください。リセットボタンではありません。

抵抗を挟むのは Raspberry Pi Pico と同じ理由です。

- 通常動作中は RP2040 が CS を High に駆動しているため、抵抗なしでボタンを押すと 3.3V を直接 GND に短絡してしまう
- 10kΩ(R2) のプルアップとの分圧で 3.3V × 1/11 ≒ 0.3V となり、確実に Low と判定される

書き込み手段は2通りあります。

| 方法 | 手順 |
| :--- | :--- |
| UF2（SW1） | SW1 を押しながら USB 接続 → ストレージとして認識 → UF2 をコピー |
| SWD（J2） | Tag-Connect ケーブルを当てて書き込み。デバッグもこちら |

## ロータリーエンコーダ

SW2 は型番未確定の EC11 互換品を想定しています。A/B 相は R15/R16（各 10kΩ）で 3.3V にプルアップし、C19/C20（各 100nF）を GND へ接続しています。R15/R16 は R2/R3/R4 と同じ C25744（0402WGF1002TCE、0402）に共通化しています。コンデンサはエンコーダ近くに配置しています。

RP2040 の内蔵プルアップは 50〜80kΩ なので、100nF だけを組み合わせると時定数は 5〜8ms になります。外付け 10kΩ により約 1ms に短縮し、内蔵プルアップだけの場合より入力インピーダンスも下げます。内蔵プルアップを併用すると約 0.83〜0.89ms です。[RP2040 データシート](https://datasheets.raspberrypi.com/rp2040/rp2040-datasheet.pdf)

外付け抵抗による追加電流は、接点が閉じた相ごとに約 0.33mA、両相が閉じていると最大約 0.66mA です。本基板の 5V→3.3V LDO を含めると、USB 入力での追加消費電力は直流分で最大約 3.3mW になります。停止位置で接点が閉じていれば待機中も消費します。

この値は、元の内蔵プルアップだけの構成より入力を強くし、消費電流と部品共通化も考慮した初期値です。参考の Alps EC11E15244B2 が規定する抵抗負荷での最低動作電流 1mA は満たさず、型番未確定の互換品の接触信頼性を保証するものではありません。また、現在の回路はコンデンサを接点へ直接接続しており、プルアップ抵抗はコンデンサの放電電流を制限しません。ファームウェアで A/B 相の遷移を検証し、採用部品の仕様と実機の回転試験で確認します。[Alps の仕様とフィルタ例](https://tech.alpsalpine.com/e/products/detail/EC11E15244B2/)

## 開発環境

- **KiCad 10.0** 以降

回路図を編集する場合、以下の点にご注意ください。

**`Tools → Update Symbols from Library` は慎重に実行してください。** KiCad 標準ライブラリ側で `Memory_Flash:W25Q128JVS` のピン位置が変更されているため、そのまま更新すると U4 が全ネットから外れます。U4 は意図的に古いキャッシュ定義のまま維持しています。

また、フィールド関連のオプション（`Update/reset field text` など）を有効にすると、電源シンボルの Value が書き換わってネット名が変わる可能性があります。

**`Tools → Update PCB from Schematic` では `Link footprints using reference designators` をオフのままにしてください。** フットプリントは Unique ID で回路図と紐付いています。古い基板との参照名の重複を使って紐付けると、異なる部品が対応付けられることがあります。

基板を編集する場合は、[`pcb/PLACEMENT.md`](pcb/PLACEMENT.md) の「やってはいけないこと」を先に読んでください。配線やビアの一括削除は、現行ネットとの接続を確認せず実行しないでください。編集後はベタを再充填し、DRC と製造データを作り直します。

GUI を開かずに状態を確認するには:

```sh
kicad-cli sch erc                                   -o erc.rpt ts52k.kicad_sch
kicad-cli pcb drc --schematic-parity --refill-zones -o drc.rpt ts52k.kicad_pcb
```

現在、ERC は 0件、`schematic parity` も 0件です。
