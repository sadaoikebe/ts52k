### 原本との照合で確かめたこと
- TC69 のネット（`tc69.net`）：SENSE ＝ C2・R3・MUX 2 個の共通端子（ピン 3）・MCU。S0 → MUX A の INH（ピン 6）と 1G04 の入力、1G04 の出力 → MUX B の INH。S1／S2／S3 → ピン 11／10／9。VEE（7）と VSS（8）は GND。列は 100 kΩ で GND へ。仕様書 §2.1 と一致。
- TC69 の `ecs_pad`：パッド 1（西の半月）が行（駆動）、パッド 2（東の半月）が列（センス）、パッド 3 がリング（GND）。貫通ビア（0.8／0.4 mm）は各半月の中、キー中心から ±1.19 mm。TC69 では 0° と 180° が混在するが、仕様書どおり TC52 は全キー 0° にする。
- Rev 0.2 の島：U5 の GPIO18〜29 は西辺（ピン 29〜41）に並ぶ。東辺のピン 4〜18 から出ていたマトリクス配線は全部なくなる。

### 判断
1. **ファイル名は `ts52k.kicad_*` のまま**にする。ブランチで分かれており、名前を変えると製造スクリプトや差分の追跡が切れる。基板のシルクと回路図のタイトルだけ TC52 にする。
2. **部品番号**：仕様書の記号（C2、R1〜R3 など）は Rev 0.2 の既存番号と重なるので、追加分は別の番号にする（対応表は下の「部品番号の対応」）。キーの番号 MX2〜MX82 は Rev 0.2 のまま。
3. **フラッシュ U4 は動かさない**（仕様書 §4 は「北西へ寄せる」としていた）。北西は USB と LDO で埋まっていて、実績のある QSPI 配線を崩すことになる。目的は「c2 の配線を QSPI から 2 mm 離す」ことなので、c2 のほうを U4 の東へ迂回させ、MX7 の電極内ビアを中心 ±1.19 mm から電極の中の別の位置へ動かして達成する。配線後に実測値をここへ書く。

### L4 の配線の位相（最重要の判断。ここを読めば続きが書ける）
列は「行1のビア → 行4（または行3）のビア → 下の帯 → MUX」という L4 上の一筆の壁になる。隣り合う列の間は、上の帯（y 46〜52.6）にしか開いていない袋になる。RP2040（U5）は c1 と c2 の間の袋の中にあるので、U5 から出る信号は L4 だけでは外へ出られない。仕様書 §4.1 の「S0〜S3 を y 100〜110 づたいに」は c2 を横切るので、そのままでは引けない。次の方法で解いた。

1. **電極の門**：センス電極（半円、半径 6.0 mm）にビアを 2 個打ち、列の配線を「上のビアで入って下のビアから出る」形にする。2 個のビアの間は L1 の電極そのものがつなぐので、L4 ではビアの間を別の配線が通り抜けられる（間隔 2 mm を両側に取る）。L2／L3 が間にあるので電極の下を通ってよい。
   - **MX13（c2）の門**：ビアを中心から (+3.0, ∓4.2)。ここを東向きに 9 本（BOOTSEL、ENC_A、ENC_B、ENC_SW、+3V3M、S0〜S3）が通る。出たら c2 と c3 の間を北へ上がり、上の帯へ入る。MX13 の駆動側ビアは (−1.19, +4.6) へ下げ、束の下に逃がす。
   - **MX3（c1）の門**：ビアを (+1.0, −5.3) 付近と (+1.2, +2.0) 付近（配線時に確定）。ここを西向きに +3V3、ADC、PURGE（＝SENSE）が通る。MX3 の駆動側ビアは (−1.19, +5.2) へ下げる。
2. **AFE は基板の西端へ**（x −2〜10.5、y 84〜100。仕様書は (32, 89)）。c1 の外側にあるので、SENSE の幹線は MX5 の西を回って下の帯の最下段（y 118.0）へ入り、どの列とも交差せずに MUX A・MUX B の南側へ届く。幹線の長さは約 235 mm で仕様書の見積もり（230 mm）と同等。U5 から AFE までは約 25 mm。
3. **下の帯には列と SENSE だけ**を入れる（仕様書どおり S0〜S3 は入れない）。西：c2 114.8／c1 116.4／SENSE 118.0。MUX A の東：c4 113.3／c5 114.9／c6 116.4／SENSE 118.0。MUX B の西：c9 113.5／c8 115.0／c7 116.5／SENSE 118.0。東：c12／c13／c14。
4. **MUX は縦置き、制御端子を北、アナログ端子を南**（裏面なので上から見て 左列 北→南＝ピン 8〜1、右列＝9〜16）。西から来る列は左列、東から来る列は右列。SENSE は南端から IC の腹の下（パッド列の間、幅 3.4 mm）を通ってピン 3 の内側へ入る。MUX A では幹線から約 9 mm の枝になる（仕様書 §5-13 の「枝を作らない」からの逸脱。MUX A の左右を列が囲むので、一筆書きにすると幹線が列を横切る。9 mm の枝は容量 1 pF 弱で、時定数には効かない）。S1〜S3・INH・VDD は北端から腹の下を通って各パッドの内側へ。
   - MUX A（中心 (76.0, 108.5)）：X5＝c3、X7＝c2、X6＝c1、X3＝c4、X0＝c5、X1＝c6、X4・X2＝GND。
   - MUX B（中心 (222.5, 110.0)）：X5＝c10、X7＝c9、X6＝c8、X4＝c7、X3＝c11、X0＝c12、X1＝c13、X2＝c14。
5. **S0〜S3 と MUX の電源は上の帯を東へ**（ENC 3 本と同じ帯）。MUX A へは c3 と c4 の間、MUX B へは c10 と c11 の間を下りる。MUX A への分岐は 1 層では引けない（バスの分岐は必ず交差する）ので、**分岐点だけ L1 の短いジャンパ**（行1 の電極の間、基板の上縁、長さ 1〜2 mm、4 本）で越える。S は走査中は静止している信号で、非同期信号ではない。
6. **アナログ電源を 2 系統に分ける**：オペアンプ用の +3V3A（R24 22 Ω＋C32 4.7 µF、AFE のそば。+3V3 を MX3 の門で持っていく）と、MUX・インバータ用の +3V3M（R26 22 Ω＋C37 4.7 µF、島の南東。束と一緒に運ぶ）。1 系統のままだと、AFE（袋の外）と束（袋の中から出る）の間で電源線が ADC／PURGE を横切る。回路図に R26／C37 を足す。
7. **行**：L1 のバスは 行1＝y 64.29、行2＝83.34、行3＝102.04、行4＝102.74（行3 と行4 は同じ行間に 2 本）。各キーは行間のビア → L4 で約 9 mm → 駆動側ビア。行4 だけ上から入る。U5 からの給電：ROW1・ROW2 は島の南西で L1 へ上げる。ROW3・ROW4 は L4 を x≈22 で y≈102 まで下ろしてから L1 へ。S0〜S3 はその南端を回り込んで MX13 の門へ向かう。
8. **エンコーダの線**（Rev 0.2 は y 56.5 を通り、行1 の中心ビアから 1.7 mm）は撤去し、上の帯へ引き直す。プルアップ R15／R16 は U5 の東へ移す。BOOTSEL の線も束に入れ、門を出てから SW1 へ戻す。
9. c2 の MX7→MX8 は U4 の東（x 43.6）へ迂回させる（判断 3 のとおり）。MX7 のセンス側ビアは (+5.3, 0) 付近へ。
10. 配線は任意角度の直線で書く（45° に揃えるのは後回し。製造上の差はない）。

### 設計の変更（前回の「L4 の配線の位相」1・5 を置き換える）
前回の案を配線に落とす前に突き合わせたところ、成立しない箇所が 2 つあった。
- S0〜S3 を西から南へ回して MX13 の門へ運ぶ経路は、MX9 の行引き込み（x 28.57、y 102.7〜111.9）に塞がれる。
- MX7 の行引き込み（x 32.15、y 54.8〜64.3）がフラッシュ U4 のパッド列の上を通っていた。

そこで次のように決め直した。
1. **MUX の選択線を A 用と B 用で別の GPIO にする**（1G04 U9 と C36 は廃止）。共有線のままだと MUX A への分岐（T 字）で必ず交差が生じ、L1 か L3 のジャンパが要る。RP2040 は GPIO が余っている（TC69 が共有＋反転にしたのは XIAO のピン数の都合）ので、MUX ごとに INH・S1・S2・S3 を 1 本ずつ出せば交差がゼロになる。電気的には各 MUX から見て TC69 と同じ。
   - GPIO3＝S3B、4＝S2B、5＝S1B、6＝INHB、8＝S3A、9＝S2A、10＝S1A、11＝INHA（U5 の東辺、ピン 5〜8・11〜14）。GPIO22〜25 は未接続にしてファームで LOW 固定（PURGE／ADC の隣が静かになる）。
   - エンコーダは GPIO0＝ENC_B、GPIO1＝ENC_A に入れ替え（上の帯での並び順の都合。ファームではピン定義の入れ替えだけ）。
   - **ファームへの影響**：`addr[c]` は「どちらの MUX か＋X 番号」。選択時は該当 MUX の INH を LOW・他方を HIGH にし、S1〜S3 を書く。INHA と INHB を同時に LOW にしない。tc52-firmware.md／tc52-zmk.md のピン表は要更新（未実施）。
2. **門は MX8（c2）と MX12（c3）**。U5 の東辺から出た束は MX8 の門（ビア (+2.0, ∓5.0)、通路幅 5.0 mm）を東へ抜ける。BOOTSEL は SW1 へ、B 用＋エンコーダ（8 本）は SW1 のパッドの間を北へ上がって上の帯（y 50.1〜52.2）へ、A 用（5 本）は SW1 の下を通って MX12 の門を抜け、c3 と c4 の間を MUX A へ下りる。MX13 は普通の電極に戻す。上の帯を使うのは B 用とエンコーダだけになり、T 字分岐とジャンパは無くなる。
3. MUX での並び（西→東）：MUX A は INHA・S1A・S2A・S3A・+3V3M（+3V3M はパッド 11 と 12 の間を通って腹へ入りピン 16 へ）。MUX B は INHB・+3V3M・S1B・S2B・S3B（全部腹の中）。
4. +3V3M は束の中で 2 本（A 用・B 用）。R26／C37 は束の南に置き、**島の中の L3 で束の下をくぐって**（仕様上 L3 は島内配線可）束の中の 2 か所のビアへ上げる。
5. MX7 の行引き込みは L3（島内）で U4 の腹の下を通す。
6. AFE の位置（西端）、MX3 の門（+3V3・ADC・SENSE を西へ）、下の帯の割り付けは前回のまま。
