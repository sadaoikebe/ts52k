# Revision 0.2 基板レイアウト

2026-11-11にブランチ claude-fable-mosfet-2026-11-11 で逆接続保護のQ1をJ3の南西へ追加した（未マージ。[配置・配線記録](placement-review/README.md)の冒頭）。その場合の製造データはBOM 21行・CPL 82点。

現在のPCBは無線版で、2026-11-10にU5を西端へ移し、GPIO割当てと西側の配置・配線を更新済み。[配置画像・変更記録](placement-review/README.md)と[現在のGPIO表](../notes/wireless-pin-assignment.md)を参照。取り込み判断は完了し、`wireless` にマージ・push済み（9986174）。無線版の製造データは2026-11-11に再生成済みで、`pcb/jlcpcb/` は無線版の出力（ガーバー、BOM 20行、CPL 81点・全て裏面、LCSC番号の欠けなし）。実機検証は未了。以下のRP2040配置・配線・DRCの記述は移行前の記録。

この文書は旧RP2040版の配置・出力時の記録。無線版のライブラリ整理後のERC/DRC結果ではない。無線版の現状は[決定事項](../notes/wireless-decisions.md)と[ライブラリ](LIBRARIES.md)を参照する。

Revision 0.2 は RP2040 を搭載した52キー基板です。回路と基板の設計・配置・配線は完了しています。基板の詳細は [回路図](ts52k.kicad_sch)、[基板データ](ts52k.kicad_pcb)、[設計ルール](ts52k.kicad_dru)を参照してください。ケースとプレートは既存版と共通です。

## 基板の構成

- 2層、板厚 1.6 mm、基板外形は約 307.23 × 80.41 mm。
- キースイッチ52個と押し込みスイッチ付きロータリーエンコーダ1個。マトリクスは6列 × 10行。
- キースイッチとエンコーダを除く実装部品は裏面（B.Cu）。JLCPCB実装対象は96点。
- USB Type-C の J1、RP2040 の U5、QSPIフラッシュの U4、12 MHz発振器の X2、書き込み・デバッグ用の J2、BOOTSEL の SW1 を搭載。
- J1のシールドはGNDに接続。J2は Tag-Connect TC2030-IDC-NL の接点・位置決め穴で、コネクタ部品の実装はありません。

主な部品の位置は次のとおりです。座標は KiCad の mm、角度は基板データの値です。

## RP2040 とマトリクス

U5 の QFN-56 は 0.4 mmピッチ、端子パッド幅 0.20 mm です。中央の GND パッドには穴径 0.30 mm のビアが4個あります。JLCPCB の2層・1 ozでの製造・実装に用いる設計で、同様のパッド・ビアを持つ製造実例は [JLCPCB向け情報](jlcpcb/README.md#rp2040-のパッドと-jlcpcb-の製造実例)に記載しています。これらの寸法を理由にガーバー出力を止める必要はありません。

| 信号 | RP2040 GPIO |
| :--- | :--- |
| col1 ～ col6 | 22, 12, 6, 13, 14, 15 |
| row1 ～ row5 | 2, 4, 16, 18, 20 |
| row6 ～ row10 | 3, 5, 17, 19, 21 |
| エンコーダ A相 / B相 | 0 / 1 |

## 配線とGND

ネットクラスの既定クリアランスは 0.20 mm、Default のトラック幅は 0.15 mm、Power のトラック幅は 0.25 mm です。基板全体の最小トラック幅は 0.15 mm です。

[カスタムルール](ts52k.kicad_dru)では、RP2040 周辺の `MCU_FANOUT` に交差する対象物同士に 0.15 mm の局所クリアランスを適用します。マトリクスの row / col トラックとビアには 0.20 mm、J2の接点と他の配線等には裏面で 0.508 mm を適用します。

表裏の GND ベタに加え、MCU・QSPI周辺に優先度の高い局所 GND ゾーンがあります。SW2 C、J1 A12/B1、C10/C12/C13 の2番はパッドごとにベタ直接接続を指定しています。他のパッドはゾーンの接続設定に従います。これらの設定を変更するとベタの充填形状や接続が変わるため、変更後は再充填して DRC を実行してください。

## 検査と製造データ

KiCad 10.0.5 での出力時の確認結果は、DRC エラー0件、未接続0件、回路図との不一致0件、シルク警告25件、ERC エラー・警告0件です。実機での電気的な動作および USB 信号品質は未測定です。

ガーバー・ドリル・BOM・実装座標の再生成と部品実装面は [JLCPCB向け出力](jlcpcb/README.md)を参照してください。回路図や基板を編集した場合は、ベタを再充填し、DRC・ERCと製造データを更新してください。

## 編集時の注意

- `Update Symbols from Library` で U4 のシンボルを標準ライブラリから無条件に更新すると、ピン位置の違いでネットが外れる可能性があります。回路図を確認してください。
- `Update PCB from Schematic` では、通常は Unique ID で対応付け、参照名だけによるリンクは使用しないでください。
- 配線やビアを一括削除する前に、現在のネットへの接続を確認してください。
- 部品、フットプリント、パッドのベタ接続設定を変更した場合は、回路図と基板の整合・接続を再確認してください。
