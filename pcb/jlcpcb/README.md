2026-10-30追記: 1V1系のC9をU5の50番ピンへ寄せ、電源配線を5.41 → 1.58 mmに短縮しました。C8は1.61 → 1.46 mm、C10は2.25 → 1.76 mmです。R13/R9/R10を北へ0.35 mm移し、USB・マトリックス・Flash側の長いQSPI配線を維持しました。最新の配置と対向GNDの測定は[配置・配線結果](../mcu-layout/README.md)を参照してください。

## 変更と検証

- 銅箔と基板外周の設計ルールを **0.25 mm** にし、表裏の GND ゾーンを再充填して基板に保存しました。JLCPCB の通常のルーター外形では銅箔まで 0.2 mm 以上が必要です。[JLCPCB 基板製造能力](https://jlcpcb.com/capabilities/pcb-capabilities)
- BOOTSEL の SW1 は、上押し式 **XKB TS-1187A-B-A-B / C318884** に変更。JLCPCB の掲載上は Basic です。高さは基板から約 1.5 mm、実装面は Bottom。裏面側から押します。[部品情報](https://jlcpcb.com/partdetail/C318884) / [メーカー図面](https://www.helloxkb.com/uploads/qingchukaiguan/TS-1187A-X-X-X.pdf)
- SW1 を裏面の (47.6, 76.2) mm、90°に配置。メーカー図面の推奨ランドと A–B／C–D の接点構成に合わせています。SW1 のコートヤードと表面のキースイッチ貫通部・位置決め穴の平面上の最小隙間は約 0.695 mm です。既存ケースの Base には広い底面があるため、組み立てたまま押すにはケース側の開口が必要になる可能性があります。基板とケースの厳密な 3D 位置合わせ・実際の押下操作は未検証です。
- **52個のキースイッチは位置・角度・面とも変更なし**。2026-10-30にU4/C11/C15/C16/R2/R14を再配置し、C11–U4の電源接続を約1.52 mm、C16–U5.10を約1.51 mmに短縮しました。QSPIの長い裏面区間の対向面GNDを確保しましたが、MCU側の引き出し・層変更部には局所的な抜けが残ります。当初の主幹603要素は座標・幅・層を維持し、MCUから既存末端への13本は裏面で接続しています。USB信号配線も維持しています。[配置・GNDの図と配線長の比較](../mcu-layout/README.md)
- KiCad 10.0.5 の DRC は、エラー 0、未接続 0、回路図との不一致 0、警告 133 件。ERC はエラー 0、U3 のライブラリシンボルとの差の警告 1 件です。DRC の警告にはフットプリントのライブラリ差、シルクの重なり、配線の枝端、X2-EN のビアが含まれます。プロジェクト設定で無効なチェックもあるため、移動部品と表面の貫通部の干渉は別途検査しました。
- 前回（2026-10-27）のSW1変更時には、別コピーでPTH穴と配線0.28 mm、パッド穴同士0.45 mm、PTHパッドの環状幅0.18 mmの追加検査も行っています。この追加ルール検査は今回のFlash再配置後には再実行していません。今回の結果は本体のDRC、回路図整合、平面干渉検査に基づきます。
- USB の R7/R8 は **22Ω・C25092** のままです。同じ Basic 部品を QSPI 側 R9–R13 と共通化し、部品種と PCBA の段取り費を抑える設計判断です。Raspberry Pi の[設計資料](https://datasheets.raspberrypi.com/rp2040/hardware-design-with-rp2040.pdf)で指定される 27Ω とは異なり、USB 波形の測定・シミュレーションは行っていません。

## データの再生成

KiCad 10 と Python 3 を用意し、KiCad 上の変更を保存したうえで、リポジトリ直下から実行します。

```powershell
python pcb/jlcpcb/export.py
```

`kicad-cli` が PATH にない場合、Windows の標準 KiCad 10 インストール先を探します。それ以外では `--kicad-cli` に実行ファイルのパスを渡します。

スクリプトは現在の回路図・基板から DRC / ERC、ガーバー、PTH・NPTH ドリル、BOM、実装座標を作成します。外周クリアランスが 0.2 mm 未満の場合、DRC エラー・未接続・回路図との不一致・ERC エラーがある場合、部品番号や実装座標が欠けている場合は停止します。作成時のソースと出力の SHA-256 は `assembly/manifest.json` に記録します。生成物は `.gitignore` の対象なので、クローン後や基板編集後に再生成してください。

| JLCPCB に渡すもの | ファイル |
| :--- | :--- |
| ガーバーとドリル | `gerber/ts52k-gerbers.zip` |
| PCBA 部品表 | `assembly/ts52k-bom.csv` |
| PCBA 配置座標 | `assembly/ts52k-cpl.csv` |

正常終了したら `assembly/export-status.txt` が `EXPORT COMPLETED` になります。失敗時には以前の出力が残ることがあるため、利用しないでください。基板・回路図・設定を変更したら再生成します。

実装面は **Bottom のみ、93 点 / 15 種**です。USB コネクタ J1 と BOOTSEL の SW1 は JLCPCB に実装してもらいます。キースイッチ 52 個とロータリーエンコーダ SW2 は手付け、Tag-Connect J2 は接点と穴だけで部品実装なしです。J1 は固定脚に PTH があるため、座標出力を SMD のみに制限すると抜けます。スクリプトは J1 を含む BOM と配置座標の参照番号を照合します。

## 発注画面で確認すること

1. 2 層、板厚 1.6 mm、銅厚 **1 oz** を選ぶ。基板外形は約 307.23 × 80.41 mm。最小配線幅 0.15 mm は JLCPCB の 2 層 1 oz の公表能力内ですが、2 oz の公表最小値 0.16 mm は満たしません。
2. BOM をアップロードし、各部品の**現在の実装在庫と見積額**を確認する。特に発振器 X2 / C27636964 の JLCPCB 実装在庫は未確認です。部品区分や在庫は変動します。
3. JLCPCB の配置プレビューで Bottom 側の J1・SW1、U2/U3/U4/U5 の向き、53 個のダイオードの極性を確認する。配置データの角度は KiCad の値であり、部品ライブラリごとの回転補正はプレビューで確認が必要です。
4. U5 の中央 GND パッドにはペースト開口と重なる 4 個の貫通ビアがあります。はんだの流入を防ぐ実装方法やビア充填の可否・費用を JLCPCB に確認する。U5 の約 0.20 mm 幅の端子パッドは同社能力表の最小 SMD パッド寸法と異なるため、この点も Gerber に基づく DFM 確認を取る。[ビア・イン・パッド](https://jlcpcb.com/help/article/via-in-pad-pofv-guide)
5. ケース底板と SW1 の高さ・押下経路、Tag-Connect の実際の挿入性を確認する。RP2040 用ファームウェアは未完成です。試作後に全キー、同時押し、USB の両向き、繰り返し起動を検証します。

JLCPCB へのアップロード、メーカーの DFM 確認、基板製造、USB 信号品質の実測・シミュレーションはまだ行っていません。
