2026-11-05。対象PCBのSHA-256は[electrical-check.json](electrical-check.json)に記録。今回は評価のみでPCBは変更していない。設計資料・結線・配線形状と簡易計算の評価であり、SPICE/電磁界シミュレーションや実機測定ではない。

## 判定

主要回路の未結線・短絡・回路図との不一致は見つからなかった。直流の給電経路とUSB・LF水晶は次工程へ進める構成。ただし、**REG0の出力配線とモジュールGNDの表裏接続は、GPIOを引く前に改善したい**。現状を電源品質確認済み、製造可能とはしない。

## 未結線と検査

現在のPCBでDRCと回路図照合、現在の回路図でERCを再実行した。

- 未結線30件：マトリクス・エンコーダ26件、J2のSWDIO/SWCLK/nRESET/VDDの4件。26件は26本のGPIOという意味ではなく、同一ネット内の切断も含む。MX2/MX8周辺やD3の切断も含まれる。
- 電源、USB、水晶、GND、リセットスイッチには未結線の指摘なし。J2のGNDは接続済み。
- 回路図との不一致0、ERC違反0。
- DRC違反103：旧配線のdangling 25、シルク・文字78。短絡・電気的クリアランス・courtyard重なりの指摘なし。
- DRCは既存設定で実施。missing_courtyard、track_not_centered_on_via、tuning_profile_track_geometries、pth_inside_courtyard、npth_inside_courtyardは無効。今回除外を追加していない。「全検査項目が合格」の意味ではない。

根拠：[DRC](drc.json)、[ERC](electrical-erc.json)、[未結線一覧・配線測定](electrical-check.json)。GPIOの南側端子へのネット変更は未実施で、回路図との一致は採用予定のGPIO割当が反映済みという意味ではない。

## 電源と充電

PCBのパッドネットで、BQ IN=USB_VBUS、OUT=VDDH、BAT=J3.1、J3.2=GNDを確認。R20はUSB_VBUS–MCU_VBUSの2.2 Ωで、BQ INに直列には入っていない。モジュールVDDH=30、DCCH=31、VDD=28、VBUS=32を確認。L1はDCCH–VDD間。VDDへ5 Vを直結する結線ではない。

USB100固定、8.2 kΩ ISET、TS固定抵抗と採用容量は維持。[TI BQ24072仕様書](https://www.ti.com/lit/ds/symlink/bq24072.pdf)のUSB100入力制限は90/95/100 mA。OUTは低電池電圧時に3.4 V典型、それ以上では電池電圧+225 mV典型。4.2 V電池なら約4.425 Vであり、VDDHへ供給する構成と整合する。電池運転時にVDDを常に3.3 V維持できるという意味ではない。ブートローダー/UICRと電池低下時の条件は既存の[起動条件](../../notes/zmk-hardware-bringup.md)を引き継ぐ。

配線中心の経路長はBQ OUT→VDDH 21.60 mm、BATコネクタ→BQ 17.53 mm。35 µm銅、20℃の銅抵抗率1.72×10⁻⁸ Ωm、全長を幅0.25 mmと仮定すると、それぞれ約42 mΩ、34 mΩ。100 mAで約4.2 mV、3.4 mV。これは片道の銅配線のみでビア・パッド・GND帰路・部品内部抵抗を含まない概算だが、幹線の長さによるDC降下は現状の主要懸念ではない。

BQの入力・出力・BAT容量への配線はそれぞれ1.85/2.86/1.65 mm。EPから入力容量GNDまで直接銅配線3.28 mm。EPには4個のGNDビアがあり、OUT容量も近傍ビアでGNDへ接続される。TIが求める短い容量接続とEP接地の方向に沿う。EP付近のF.Cu島はB.Cu経由で接続されており、ベタ面積だけで熱抵抗や温度上昇を保証しない。5 V→3 V、100 mAの単純例では損失は約0.2 Wで、実際の分配電流・電圧・放熱によって変わる。

R20と4.7 µFの公称時定数は10.34 µs。モジュールVBUS枝10 mAという仮定なら降下22 mV、抵抗損失0.22 mW。USB入力に直結する外付け容量の公称合計は5.7 µF。既知の固定充電の制約は[電源入力ノート](../../notes/wireless-power-input.md)のままで、新たな充電制御は要求しない。

## REG0とパスコン：次に改善する箇所

[Raytac Version L §8.1](https://www.raytac.com/download/index.php?index_id=43)のVDDH給電・DCCH–VDD外付けL構成と整合。部品値を変える理由はない。問題は実装配線のまとまり。

| 経路 | 配線長 mm |
| --- | ---: |
| U5 DCCH → L1 | 2.594 |
| L1 → U5 VDD | 9.645 |
| L1 → C27 4.7 µF | 11.843 |
| L1 → C28 1 µF | 4.438 |
| U5 VDD → C31 100 nF | 2.348 |
| U5 VDD → C27 4.7 µF | 3.898 |

DCCH側はB.Cu、0.30 mm、ビアなしで短い。一方L1出力が北から西側容量列を回り込み、主容量C27まで長い。C28の1 µFが途中にあるため「出力容量がない」わけではないが、DCCH側だけを見てREG0全体を短いと評価するのは誤り。**L1出力・C27・VDDを近くまとめる配置配線を優先する**。これはメーカーの長さ上限への違反を確認したという意味ではなく、寄生インダクタンスと共通配線を減らすための改善判断。

C28〜C30はVDDから約6〜8 mmで、すべてを「直近のパスコン」とは呼べない。C31とC27が近傍容量を担い、補助容量を追加する現在の構成は維持する。容量の個数・値ではなく、ループの配線を改善する。

## GND

[前回の銅箔形状評価](return-path-check.json)と今回PCBのハッシュ一致を確認。USB D+/D−、DCCH、水晶の中心線と左右0.25 mmの範囲はF.Cu GND欠損0。ただし板厚1.6 mm級の基板では、左右0.25 mmだけで帰路電流の全分布を覆うわけではない。

U5のGND端子33の最寄りGNDビアは中心間約0.80 mm。一方、南側の端子15は約5.96 mm、端子1/2は約4.71/4.31 mm、端子55は約3.50 mm。これは直線距離であって実帰路長ではない。B.Cuベタにも接続されるためGND断線ではないが、**南側と右側に局所的なGNDビアを追加できるか検討する価値がある**。水晶負荷容量のGNDビアは約0.8 mm以内。新たなビアもアンテナkeepoutとGPIO通路を守る。

## USB

[nRF52840はFull-Speed 12 Mbps](https://docs.nordicsemi.com/r/bundle/ps_nrf52840/page/keyfeatures_html5.html)。D+/D−は幅0.20 mm、全B.Cu、ビアなし。コネクタの重複接点からモジュールへの各経路は次のとおり。ネット全体の銅配線総延長をスキューとして使わない。

| 経路 | D+ mm | D− mm | 長さ差 mm |
| --- | ---: | ---: | ---: |
| J1 A6/A7 → U5 | 11.098 | 13.959 | 2.861 |
| J1 B6/B7 → U5 | 12.298 | 11.222 | 1.076 |

伝搬速度を150 mm/nsとした概算では最大差は約19 ps、最長経路の遅延は約93 ps。Full-Speedの4 ns最小立上りに対して小さく、長さ合わせの蛇行を増やす理由は見つからない。[Silicon Labs AN0046 §3.3](https://www.silabs.com/documents/public/application-notes/an0046-efm32-usb-hardware-design-guidelines.pdf)のFull-Speed短配線の扱いを参考にした。別MCUの直列抵抗や回路は転用しない。

ただし差動90 Ωを確認したわけではない。現在の設定は層間1.51 mm、εr=4.5、銅35 µmで、ペア間隔は一定でなく同層GNDも存在する。幅だけから90 Ωと認定できず、上の遅延計算もインピーダンス解析ではない。約14 mm以下の短いFull-Speed配線として、現段階では全面引き直しより電源側改善を優先する。

D89/D90は信号経路上にあり、GND側の最寄りビアは約0.78/0.81 mm、VBUS保護D91は約0.85 mm。ESD帰路は近傍にあるが、部品のクランプ値とDRCだけで製品のESD耐性は認定しない。

## 水晶・起動・RF

U5→水晶は2.96/2.67 mm、ビアなし、負荷容量は隣接。32.768 kHz発振回路でこの約0.29 mm差をUSBのようなスキュー問題として扱わず、寄生容量・GND・スイッチング線からの分離を優先する。12 pF×2は等価直列6 pFで、CL=9 pFとの差はモジュールと基板の寄生容量を含む。現物の寄生容量・負性抵抗余裕を求めていないので、起動時間・50 ppmは未実証。先行構成を維持する。

アンテナ領域は両面銅箔keepoutを保持し、現在のDRCでkeepout違反なし。ただしRaytacが推奨する基板端配置とは違い内側の配置なので、通信距離や真鍮板の影響まで合格とはしない。既存の配置制約の中で進め、試作で確認する。

J2は未結線なので、生モジュールの初回SWD書き込みができる完成状態ではない。配線済みRESETスイッチは別。製造前にJ2を配線し、VDD参照・SWD・リセットを照合する。機材購入は今回の進行条件にしない。

## 次の優先順位

1. L1出力〜C27〜VDDの接続を短くまとめる。採用部品・容量は維持。
2. U5の南側・右側GND端子付近の表裏接続を補強する。
3. 変更後にベタ再充填、DRC、USB/水晶/電源の帰路を再確認し、その後GPIO・J2へ進む。

リップル・起動時波形・USBアイ・ESD・LF精度・BLE到達距離は実機確認が残る。これらの未測定を理由に部品選定や固定充電の決定へ戻さない。
