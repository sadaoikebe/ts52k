# 2026-11-10 モジュール左端移設のスクリプト（記録）

コミット `891e14f` の基板を、U5を左端へ移した現在の基板へ作り替えたときの記録。座標は当時の基板を前提にしており、現在の基板へ再実行するものではない。

| ファイル | 内容 |
| --- | --- |
| `a1_sch_pins.py` | 子シート `mdbt50q.kicad_sch` のGPIO18本を付け替える（配線・階層ラベル・NC） |
| `a2_prep.py` | `ANT_NO_FILL` と旧モジュール位置に依存する配線を除去し、U5を移してパッドのネットを回路図に合わせる。結果がコミット `6b41900` |
| `build.py` | `6b41900` の基板を取り出し、部品を再配置して `route.py` を実行、参照名シルクを置き直してDRCを取る。引数は実行する段階の上限（8で全部） |
| `route.py` | 配線本体。段階2＝水晶と電源コンデンサ群、3＝北側・束・バス入口、4＝南側・USB・電源、5＝リセットとSWD、6＝モジュールのGNDと `ANT_EDGE`、7＝GNDスティッチ |
| `lib.py`、`drc.py` | 編集とDRC集計のヘルパー |

`build.py` は `/tmp/w/orig.kicad_pcb`（`git show 891e14f:pcb/ts52k.kicad_pcb`）から下段バス入口の線分を写すので、実行前に用意する。
